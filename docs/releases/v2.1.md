A small update to v2.0 that makes setup easier on a new machine. Detection and rendering are unchanged.

**Download:** `RifeGapfill-v2.1.exe` (GUI v2.1, core v2.0.1). It's a standalone exe, so you don't need Python.

**New in v2.1**
- **ffmpeg download:** a Download… button next to the ffmpeg field fetches Gyan's release essentials build for Windows (about 110 MB), with Gyan's GitHub mirror as a fallback. Only `ffmpeg.exe` and `ffprobe.exe` are kept, in an `ffmpeg` folder next to the program.
- **One startup offer:** if RIFE or ffmpeg is missing, the app offers to download whichever is missing, in a single question.
- **Running from a subfolder:** RIFE and ffmpeg are now also found in the folder above the exe, e.g. when running from `dist\`, and in `%LOCALAPPDATA%\RifeGapfill`.
- **Built on GitHub:** this exe was built and tested by GitHub Actions from the tagged source.

**Setup on a new machine:** start `RifeGapfill-v2.1.exe` and say yes to the download offer. That's all.

See the [v2.0 release](https://github.com/nilsfriden/rife-gapfill/releases/tag/v2.0) for what the tool does and how it was tested.

Windows SmartScreen may warn about the exe because it isn't code-signed.
